04

三轴力矩

定义、符号与坐标约定
Mx

滚转力矩

绕弹体纵轴 x 的力矩。它由副翼（本模型中由尾翼差动等效）与侧滑耦合产生，决定弹体的滚转角速度与滚转姿态。右翼下沉为正。

Mx = q∞ · S · b · Cl
Mz

俯仰力矩

绕弹体横向轴 z 的力矩。迎角与升降舵偏转改变尾部法向力，从而绕质心产生抬头或低头力矩；静稳定弹体的 Cmα 为负。

Mz = q∞ · S · d · Cm
My

偏航力矩

绕弹体法向轴 y 的力矩。由侧滑角与方向舵产生，决定弹体在水平面内的指向；正侧滑（机头偏左）产生向风的右偏力矩，故静稳定的 Cnβ 为负。

My = q∞ · S · d · Cn

坐标约定（苏系 / 俄中教材惯例） 弹体坐标系 O-xyz 为右手系：+x 指向弹头，+y 指向弹体上方，+z 指向弹体右侧。按右手定则：绕 +x 的正力矩使右翼下沉（滚转），绕 +z 的正力矩使弹头抬起（俯仰），绕 +y 的正力矩使弹头左偏（偏航）。图中力矩矢量从质心起绘，长度按各轴独立量程归一，仅示意方向与相对大小。

05

气动模型

线性气动导数模型

页面采用线性气动导数模型：力矩系数由静稳定项、操纵项与角速度阻尼项叠加，再乘以动压换算为力矩。动压 q∞ = ½ ρ V² 由国际标准大气与马赫数给出。

Cl = Clβ·β + Clδa·δa + Clp·(p·b / 2V) + Clδr·δr
Cm = Cm0 + Cmα·α + Cmδe·δe + Cmq·(q·d / 2V)
Cn = Cnβ·β + Cnδr·δr + Cnr·(r·b / 2V)

参考面积 S = πd²/4；俯仰/偏航参考长度取弹径 d，滚转参考长度取翼展 b。舵偏输入为控制指令角（°），正指令产生同号指令力矩。α、β 超过 18° 后按平滑因子衰减，近似非线性失速。系数为公开资料量级估算，用于教学演示，非风洞或计算流体力学结果。

符号说明 Cn 采用苏系符号（+y 向上、机头左偏为正），故 Cnβ < 0 才表示航向静稳定；它与美系（+y 向右、+z 向下）的偏航力矩系数互为相反数。
